# 📂 File Compressor and Decompressor

A Java desktop tool that allows users to **compress (zip)** and
**decompress (unzip)** multiple files through an easy-to-use
**JavaFX GUI**. Built with **JavaFX** and the `java.util.zip`
package, it provides efficient file archiving and extraction
capabilities.

---

## ✨ Features 
- ✅ Select multiple files to compress into a ZIP archive
- ✅ Decompress and extract files from existing ZIP archives
- ✅ Progress bar for better UX on large files
- ✅ Logs compression and decompression status
- ✅ Standalone executable JAR for quick usage

## 🚀 How to Run

1. **Clone or Download** the repository: ```bash
git clone https://github.com/your-github-profile/FileCompressorDecompressor.git
cd FileCompressorDecompressor ````

3. **Make sure you have installed:**

* Java JDK **17+**  JavaFX SDK (compatible with your Java
version)

3. **Run the JAR file:**

```bash
java --module-path /path/to/javafx-sdk/lib --add-modules javafx.controls,javafx.fxml -jar FileCompressorDecompressorApp.jar
```

4. **Use the GUI** to select files and compress or decompress.
